# Getting help

Vaneta OS is in development and has not been released yet.

- Members of the organization: open an issue with the matching form in the repository the question concerns, or ask the project lead.
- Security problems: follow [SECURITY.md](SECURITY.md), never a public channel.

Public documentation, a support desk and a community forum will follow with the first release, at docs.vanetaos.com, support.vanetaos.com and forum.vanetaos.com.
