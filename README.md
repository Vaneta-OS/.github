# Vaneta OS organization files

This public repository holds the profile of the [Vaneta OS](https://github.com/Vaneta-OS) organization and the community files GitHub uses for every repository in it that has none of its own:

| File                       | Purpose                                               |
| -------------------------- | ----------------------------------------------------- |
| `profile/README.md`        | The organization profile                              |
| `ISSUE_TEMPLATE/`          | Bug report, feature request and task forms            |
| `PULL_REQUEST_TEMPLATE.md` | The pull request description template                 |
| `CONTRIBUTING.md`          | Branches, commit messages, pull requests and releases |
| `CODE_OF_CONDUCT.md`       | How we work with each other                           |
| `SECURITY.md`              | How to report a vulnerability                         |
| `SUPPORT.md`               | Where to get help                                     |
